- 本轮目标：除闯关模块外，完成儿童端、家长端、学习内页和公共状态的正式 UI，并逐批换入 HTML。

## 1. 本轮边界

### 1.1 纳入范围

- 儿童端：首页、首次初始化、学习任务内页、奖励、星星账单。
- 家长端：概览、学习报告、我的小孩、任务设置、奖励设置、教材内容。
- 公共交互：角色切换、兑换确认、奖励审批、完成反馈、空状态、错误提示。
- 公共组件：状态栏、顶部栏、底部导航、按钮、卡片、表单、标签页、状态标签和弹窗。

### 1.2 明确排除

- 闯关一级页面。
- 单元主题岛详情。
- 18 个岛内关卡及其游戏状态。
- 闯关规则弹窗、徽章、整岛重玩和全部岛屿完成页面。
- APK 制作及安卓原生硬件状态。

底部导航继续保留“闯关”入口，但本轮不改变闯关页面视觉和逻辑。

## 2. 设计与实现原则

1. 功能、数据和文案以 PRD 与现有 HTML 为准。
2. 颜色、字体、圆角、阴影、间距和角色风格以 UI 设计规范及已确认 Figma 页面为准。
3. Figma 页面优先使用组件实例，不复制后脱离主组件。
4. HTML 只换视觉层，不改业务逻辑、数据结构、路由和事件。
5. 插画使用独立 PNG/WebP，图标使用 SVG；不得把完整页面导出为一张图片。
6. 儿童学习内页主要按钮一行一个，点击区域不小于 48 × 48px。
7. 每完成一批进行一次简单功能验证；详细走查只在用户明确要求时执行。
8. 每批确认后保存 Git 版本，确保可以回滚。

## 4. 第一批：儿童端核心闭环

### C-00 首次初始化

入口：新安装、没有小孩资料或本地数据恢复失败。

内容：

- Happy 英语欢迎语。
- 创建第一个小孩资料。
- 头像选择。
- 小孩名称输入。
- “开始使用”主按钮。
- 本地保存说明。

必须绘制状态：

- `C-00-01` 默认空白状态。
- `C-00-02` 已选择头像。
- `C-00-03` 名称为空校验。
- `C-00-04` 资料创建成功并进入首页。
- `C-00-05` 数据恢复提示。
- `C-00-06` 本地保存失败提示。

### C-01 儿童首页

入口：儿童端默认首页。

内容：角色欢迎区、开始学习、今日进度、今日星星、今日任务、今日复习、底部导航。

必须绘制状态：

- `C-01-01` 今日计划刚生成，全部未完成。
- `C-01-02` 部分任务已完成。
- `C-01-03` 有今日复习任务。
- `C-01-04` 今日无复习。
- `C-01-05` 今日任务全部完成。
- `C-01-06` 当前单元或全部学习内容已完成。
- `C-01-07` 当前没有可安排的学习内容。
- `C-01-08` 系统通知条：数据恢复或保存失败。

说明：`C-01` 继续以节点 `10:3` 为视觉基准，不重新创造另一套首页风格。

### C-02 学习任务内页模板

共用结构：状态栏 → 返回导航 → 任务信息 → 主互动区 → 单列操作按钮 → “还不熟”区域。

#### C-02A 听一听

- 示范音频未播放。
- 音频播放中。
- 播放完成，可重新播放。
- 播放失败提示。
- 体验完成，可提交任务。

#### C-02B 跟我说

- 等待播放示范音频。
- 等待开始录音。
- 录音中。
- 录音已停止。
- 播放自己的录音。
- 可以重新录音。
- 录音体验完成，可提交任务。

说明：麦克风权限、音频路由和系统中断由安卓正式整合补齐；本轮 Figma 与 HTML 只展示可表达的视觉状态。

#### C-02C 看图找一找／认读

- 默认未选择。
- 选中选项。
- 回答正确。
- 回答错误并鼓励重试。
- 连续答错 `1/3`、`2/3`。
- 第 3 次答错，自动加入复习。
- 体验完成，可提交任务。

#### C-02D 描一描／写一写

- 默认空白书写区。
- 书写中。
- 已完成书写。
- 清除并重写。
- 体验完成，可提交任务。

#### C-02E 单元复习

- 默认复习任务。
- 复习进行中。
- 复习完成。
- 已加入待复习队列。

#### C-02 公共复习状态

- 未标记“还不熟”。
- 孩子主动标记成功。
- 已由其他规则加入复习，按钮禁用。
- 撤销孩子主动标记。
- 重复点击不重复加入。

### C-03 学习结果弹窗

- `C-03-01` 单项任务完成，获得 3 星。
- `C-03-02` 今日全部任务完成，展示今日获得星星。
- `C-03-03` 当前全部学习内容完成。
- `C-03-04` 重复提交，不重复加星。

### C-04 儿童奖励一级页

内容：星星总数、切换家长端、奖品图片、标题、备注、价格和兑换操作。

必须绘制状态：

- `C-04-01` 无奖品空状态。
- `C-04-02` 可兑换。
- `C-04-03` 星星不足。
- `C-04-04` 待家长确认。
- `C-04-05` 家长未同意，可重新申请。
- `C-04-06` 审批失败，可重新申请。
- `C-04-07` 已兑换并显示审批时间。
- `C-04-08` 多奖品纵向滚动列表。

说明：继续以奖励节点 `98:126` 为视觉基准。

### C-05 奖励兑换确认弹窗

- 奖品标题。
- 所需星星。
- 家长同意后的预计余额。
- “确认申请”。
- “再想一想”。
- 重复申请拦截提示。

### C-06 星星账单

- `C-06-01` 无账单记录。
- `C-06-02` 只有收入。

- `C-06-04` 长账单滚动。

## 5. 第二批：家长端管理闭环

### P-01 家长概览

内容：今日完成、今日学习时长、当前计划、奖励审批、最近处理。

必须绘制状态：

- `P-01-01` 今日无完成记录。
- `P-01-02` 今日部分或全部完成。
- `P-01-03` 暂无兑换申请。
- `P-01-04` 有一条或多条待审批申请。
- `P-01-05` 最近同意、拒绝和审批失败记录。

### P-02 奖励审批弹窗

- `P-02-01` 确认同意，提示扣除星星。
- `P-02-02` 确认拒绝，提示不扣星星。
- `P-02-03` 审批时星星不足。
- `P-02-04` 奖品已被删除。
- `P-02-05` 申请已经处理，禁止重复操作。

### P-03 学习报告

内容：`{小孩名称}学习报告`、今日学习记录、今日复习记录、听说读写概况、复习建议。

必须绘制状态：

- `P-03-01` 今日无学习记录。
- `P-03-02` 有学习记录。
- `P-03-03` 今日无复习记录。
- `P-03-04` 有复习记录。
- `P-03-05` 无复习建议。
- `P-03-06` 有多条可勾选建议。
- `P-03-07` 部分建议已指定。
- `P-03-08` 全部建议已指定，主按钮禁用。
- `P-03-09` 添加指定复习成功反馈。

### P-04 角色切换弹窗

- `P-04-01` 儿童端切换家长端。
- `P-04-02` 家长端切换儿童端。
- `P-04-03` 密码为空。
- `P-04-04` 密码不足 6 位或格式错误。
- `P-04-05` 密码错误。
- `P-04-06` 密码正确并切换成功。
- `P-04-07` 取消后留在原页面。

说明：继续以节点 `112:14` 为视觉基准。

## 6. 第三批：设置与内容管理

### S-01 设置框架

结构：顶部栏、我的小孩／奖励设置／教材内容三个标签页、底部家长导航、版本信息。

状态：默认标签、切换标签、长内容滚动、固定安全区。

### S-02 我的小孩

- 当前头像和名称。
- 默认头像。
- 选择新头像后的预览。
- 名称为空或超长校验。
- 保存成功。
- 图片格式不支持。
- 图片超过 12MB。
- 图片压缩失败或本地保存失败。

### S-03 任务设置

- 每日任务数量 1–4 项。
- 学习时长 5／10／12／15 分钟。
- 学习提醒时间。
- 指定复习单元。
- 已指定具体复习内容。
- 下一次自动计划预览。
- 无可安排内容。
- 保存成功并同步儿童端。

### S-04 奖励设置

- `S-04-01` 无奖励空状态。
- `S-04-02` 奖励列表。
- `S-04-03` 新增奖励表单。
- `S-04-04` 编辑奖励表单。
- `S-04-05` 图片选择与预览。
- `S-04-06` 标题、星星价格和备注校验。
- `S-04-07` 删除确认。
- `S-04-08` 有待审批申请时禁止删除。
- `S-04-09` 删除最后一项后恢复空状态。

### S-05 教材内容

- 册—单元—目标—词汇—表达—技能—任务—复习关系。
- 三个试点单元列表。
- “内容待核对”状态。
- 后续教材确认后的“已核对”状态预留，不在本轮伪造已授权内容。

## 8. 不在 HTML 批量 UI 中完成的状态

以下状态只在 Figma 中建立视觉说明，最终由 Android 原生实现和真机验证：

- 麦克风首次授权、临时拒绝和永久拒绝。
- 录音设备被占用。
- 来电、后台、锁屏导致的录音中断。
- 扬声器、有线耳机和蓝牙耳机路由切换。
- 系统媒体音量为零或播放无声。
- Android 通知权限和系统提醒调度。
- 系统相册不可用、存储不足和文件读取失败。

完整要求见：`安卓正式整合待补状态_20260811_V1.0.md`。

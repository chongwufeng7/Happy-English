## 3. 批次 A 必须补齐的组件

### A1. 儿童学习控件

1. `Learning Control / Audio`
   - 播放、播放中、暂停、加载失败。
2. `Learning Control / Record`
   - 未授权、待录音、录音中、录音完成、播放录音、重新录音、录音失败。
3. `Self Review`
   - “会了”和“还不熟”两种选择状态。
4. `Option Card`
   - 默认、选中、正确、错误、禁用。
5. `Writing Canvas`
   - 空白、书写中、已完成、清空确认。

### A2. 页面结构与反馈

1. `Child Inner Top Bar`
   - 返回、页面标题；不显示一级页面的星星与家长端入口。
2. `Generic Empty State`
   - 无今日任务、无复习任务、无奖励、无账单记录。
3. `Notice Banner`
   - 普通说明、需要复习、权限提醒、网络或资源异常。
4. `Result Panel`
   - 任务完成、部分完成、失败后重试。
5. `Confirm Dialog`
   - 确认兑换、清空书写、退出未完成任务。
6. `Ledger Row`
   - 星星收入、星星支出、时间与来源动作。

### A3. 儿童初始化

1. `Avatar Picker`
   - 默认头像、已选头像、上传中、上传失败。
2. `Form Field`
   - 默认、聚焦、已填写、错误、禁用。

## 4. 已有组件需要补充的状态

1. 任务行：增加“复习任务”“进行中”“不可用”状态。
2. 顶部栏：增加儿童内页形态；一级页和内页的信息规则分开。
3. 弹窗：抽离通用弹窗容器，保留密码弹窗的专用输入内容。
4. 奖励卡：补充“兑换被拒绝/重新可兑换”状态，用于家长拒绝申请后的回退。
5. 按钮：不增加新的视觉风格，只复用现有三种按钮和十二种状态。

## 5. 视觉冲突与处理原则

1. 首页未使用组件实例，而组件库已较完整。批量页面以组件库为准，首页仅做结构性组件化，不做视觉重设计。
2. 奖励页已经使用部分按钮实例，继续沿用，不重新绘制按钮。
3. 现有外部公共组件库与 Happy 英语的绘本风不一致，不引入 Material、iOS 或 Simple Design System。
4. 所有新组件继续使用现有 Happy 变量、文字样式和阴影样式，不新增重复色值与字号。
5. 缺少的角色插画仅作为图片素材；按钮、状态、输入框、导航和图标坚持使用 Figma 原生可编辑图层。

## 6. 批量制作顺序

### 批次 A：儿童端（先执行）

1. 补齐 A1、A2、A3 组件。
2. 初始化与首次使用页面。
3. 今日任务入口及听、说、认读、书写内页。
4. 任务完成、失败、权限与空状态。
5. 奖励不同状态、兑换确认与星星账单。
6. 只做一次简要结构验证和关键状态切换验证。

### 批次 B：家长端

1. 家长首页、学习报告、今日学习记录、今日复习记录。
2. 复习建议多选、制定复习内容、计划空状态与自动生成提示。
3. 复用批次 A 的弹窗、空状态、表单和提示组件。

### 批次 C：设置端

1. 我的小孩：名称、头像、当前小孩与任务设置。
2. 奖励设置：新增、编辑、删除、上传图片、价格、标题和备注。
3. 教材内容与版本信息。
4. 预留多小孩数据归属关系，但本期界面只展示一个当前小孩。

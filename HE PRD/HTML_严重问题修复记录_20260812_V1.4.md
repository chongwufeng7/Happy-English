# Happy 英语 HTML 严重问题修复记录

- 日期：2026-08-12
- HTML 版本：V1.4
- 范围：低保真业务逻辑与已确认儿童端 UI
- 多小孩策略：仅保留数据结构，本期界面不提供新增、删除或切换操作

## 本版本修复

1. 奖励申请增加标题、价格、图片和备注快照；提交后的申请、审批及历史记录不再受奖品模板后续编辑影响。
2. 家长审批使用申请时的价格快照扣除星星，避免申请价格与实际扣除不一致。
3. 关键编辑操作统一校验本地保存结果；保存失败时恢复操作前数据，不再显示成功反馈。
4. 覆盖小孩建档、资料修改、奖励新增／编辑／删除、复习指定、任务设置和奖励审批等关键保存流程。
5. 小孩名称等用户输入在进入 HTML 页面时统一转义，避免特殊字符破坏页面结构。
6. 保留儿童端导航“学习、冒险、奖品”和首页主图定位修正。

## 后续 UI 约束

家长端沿用儿童端颜色、字体、圆角、卡片、按钮、图标与插画体系。当前只显示唯一小孩，不出现多小孩选择器或管理入口。

# Happy 英语｜产品体验修复分阶段

## 一、HTML 产品形态阶段：进入 UI 设计前必须确认

本阶段只验证产品结构、流程、状态和数据关系，不追求最终视觉效果。

### 必须修复

1. 今日任务必须先完成对应体验，才能提交并获得星星。
2. 首页“开始学习”进入第一个未完成任务；全部完成后显示“今日任务已完成”。
3. 孩子标记“还不熟”后可以撤销；连续答错 3 次仍自动加入复习。
4. 家长端展示自动计划组成：复习数量、新学数量、预计时长和具体内容。
5. 闯关首页只展示儿童能理解的核心规则，完整规则按需查看。
6. 奖励申请需要区分可兑换、星星不足和等待家长确认。
7. 学习、复习、闯关、星星和奖励数据继续按小孩 ID 独立保存。

### 已确认，无需重复修改

- 儿童端与家长端通过密码 `123456` 切换。
- 连续答错 3 次自动加入复习。
- 家长报告展示复习建议产生原因。
- 奖品由孩子申请、家长审批，批准后扣星并写入星星账单。
- 每座岛 6 关、顺序解锁、整岛完成后可重玩且不重复增加星星。

## 二、UI 设计阶段：产品逻辑确认后处理

1. 建立正式配色、字体、卡片、按钮、图标及插画规范。
2. 将奶牛猫、紫色变色龙、鹦鹉等角色资产替换到页面。
3. 把主题岛路线制作成真正的游戏地图。
4. 调整字号、留白、点击区域、状态层级和空状态。
5. 对齐儿童友好、明亮活泼、温柔治愈、简洁高级的视觉方向。

## 三、APK 与安卓适配阶段：不阻塞当前 HTML 验收

1. 安卓状态栏、系统导航栏、全面屏和安全区适配。
2. 底部导航在不同屏幕高度下不遮挡内容。
3. 软键盘弹出、系统返回键和横竖屏策略。
4. 扬声器、有线耳机、蓝牙耳机的音频路由。
5. 麦克风权限、录音、重录、回放及录音中断恢复。
6. 相册权限、头像上传、自动压缩和异常图片处理。
7. 弱网、离线、本地数据迁移和安装升级验证。

## 四、进入 UI 设计的验收门槛

- 儿童端今日学习闭环可完整点击完成。
- 自动计划规则在首页和家长端显示一致。
- 主动复习与自动复习均能进入儿童端。
- 三座主题岛的解锁、过关、重玩和星星规则一致。
- 奖励申请、审批、扣星和星星账单一致。
- 刷新页面后关键状态仍能保存。
- 不再存在影响产品判断的开发说明或含糊操作名称。

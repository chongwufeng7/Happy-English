## 一、产品原则

- 儿童友好：大字体、大按钮、低认知负担、操作一行一个。
- 轻松学习：答错不扣星、不排名、不进行同伴比较。
- 每日短练：单次约 10–15 分钟，系统自动生成当天内容。
- 家长可控：家长可以调整计划、指定复习、审批奖励和查看报告。
- 内容谨慎：正式制作前必须核对学校实际教材、音频来源和版权。
- 数据独立：学习进度、星星、复习和闯关数据按小孩 ID 独立保存。

## 二、产品角色与信息架构

### 2.1 儿童端

底部一级导航仅保留：

```text
学习｜冒险｜奖品
```

主要功能：

- 首页：角色欢迎区、今日进度、今日星星、今日任务、今日复习。
- 冒险：第二期保留一级入口并展示“敬请期待”；主题岛、连续关卡、徽章与重玩功能在第三期实现。
- 奖励：奖品兑换、星星总数、星星账单入口；无奖品时显示空状态并引导家长设置。
- 学习内页：听、说、认读、描写/书写、录音、回放和重新录音。
- 主动复习：孩子可以把“还不熟”的任务加入复习。

儿童端一级页面名称显示在左上角，右上角显示“切换家长端”；总星星只在“奖励”页面显示。内页采用“返回＋页面名称”的独立导航，不显示底部一级菜单。

### 2.2 家长端

底部一级导航：

```text
概览｜报告｜设置
```

主要功能：

- 概览：今日完成、今日学习时长、当前计划和奖励审批。
- 报告：今日学习记录、今日复习记录、听说读写概况和复习建议。
- 设置：我的小孩、奖励设置、教材内容、头像与名称管理、任务设置和版本信息。

儿童端和家长端相互切换均需输入密码 `123456`，弹窗显示在屏幕中央。

## 三、总体实施分期

```text
第一期：基础学习与安卓硬件闭环
        ↓
第二期：核心学习、家长管理、奖励与视觉整合
        ↓
第三期：冒险闯关、长期成长、多孩子与扩展能力
```

## 四、第一期：基础学习与安卓硬件闭环

> 一期-3 已取消，不再作为独立阶段。UI 与 APK 的正式整合并入二期-6。

### 一期-1：核心学习闭环

状态：已有安卓验证版，后续需与第二期功能合并回归。

功能：

- 儿童首页和今日任务。
- 跟读、认读、描写/书写。
- 完成任务获得星星。
- 本地保存学习进度。
- 任务完成结果反馈。

核心流程：

```text
打开 App → 查看今日任务 → 完成学习 → 获得星星 → 返回首页
```

验收标准：

- 孩子可以独立进入学习任务。
- 主要操作按钮清楚、易点。
- 完成任务后星星和进度正确更新。
- 退出并重新打开后数据仍保留。
- 不出现排名、竞赛、同伴比较或错误扣分。

### 一期-2：安卓音频与手机硬件适配

状态：已有验证实现，正式 APK 合并时需进行多机型回归。

功能：

- 手机扬声器播放英文。
- 麦克风权限申请与拒绝提示。
- 录音、停止、回放和重新录音。
- 手机扬声器、有线耳机和蓝牙耳机适配。
- 播放失败、录音失败、静音和低音量提示。

验收标准：

- 示范音频可从当前安卓音频输出设备播放。
- 首次录音时正确申请麦克风权限。
- 录音完成后可以回放并重新录制。
- 切换扬声器、有线耳机和蓝牙耳机后流程不中断。
- 权限拒绝或硬件不可用时给出儿童和家长都能理解的提示。

## 五、第二期：产品逻辑、教材试点与正式整合

### 二期-1：教材核对与内容模型

状态：进行中。

功能：

- 核对广州小学一年级实际使用的英语口语教材版本和版次。
- 建立“册—单元—主题—目标—词汇—表达—技能—任务—复习”的内容结构。
- 确定正式音频、插画和文字的授权方式。
- 用学校实际发放的 2026 年教材复核目录、顺序和内容。

验收标准：

- 教材名称、版本、版次和内容来源明确。
- 每个单元有可核对的学习目标和内容范围。
- 未经授权的音频、课文和插图不进入正式 APK。
- 当前原型示例内容与正式教材内容清楚区分。

### 二期-2：产品框架与每日学习计划

状态：HTML 低保真已实现，并于 2026-08-08 完成回归验收。

功能：

- 儿童端与家长端信息架构。
- 一级导航与内页返回规则。
- 每日计划按“小孩 ID＋日期”自动生成。
- 没有复习时安排 3 项新内容；有复习时优先 1 项复习＋2 项新内容。
- 家长未重新设置时沿用最近配置。
- 当天计划保持固定；家长修改、孩子主动标记或连续答错可触发重新排程。
- 次日仅清零今日进度、今日星星和今日记录，不清除长期数据。

验收标准：

- 每天首次打开可以自动生成计划，不要求家长每日操作。
- 同一天反复打开，计划不会随机变化。
- 次日自动刷新今日数据，总星星、历史记录和单元进度不丢失。
- 每个孩子拥有独立计划与学习数据。

### 二期-3：家长端与孩子资料

状态：HTML 低保真已实现，并于 2026-08-08 完成回归验收。

功能：

- 使用密码 `123456` 在儿童端和家长端之间切换。
- 家长概览、报告和设置三个一级模块；任务设置位于“设置—我的小孩”下方。
- 修改小孩名称。
- 点击头像从本机相册选择图片，并自动压缩至最大边 512px。
- 设置“我的小孩”“奖励设置”和“教材内容”三个标签页。
- 家长可为当前小孩新增、编辑和删除奖励，上传并压缩奖励图片，设置标题、星星价格和备注。
- 数据结构预留多个小孩，每个小孩关联独立学习数据。
- 设置页底部展示当前原型版本号 `V1.5`。

验收标准：

- 切换弹窗位于屏幕中央，密码错误时不能切换。
- 小孩名称会同步到欢迎语、对话和学习报告。
- 头像选择和压缩不会造成页面卡死或本地存储异常。
- 当前小孩的数据不会与未来其他孩子的数据混淆。

### 二期-4：复习、报告、星星与奖励

状态：HTML 低保真已实现，并于 2026-08-08 完成回归验收。

功能：

- 孩子主动点击“标记还不熟”。
- 同一互动练习连续答错 3 次自动加入复习；答对后连续错误计数清零。
- 家长端生成复习建议，显示产生原因。
- 家长可多选复习建议并添加为指定复习内容。
- 学习报告展示“今日学习记录”和“今日复习记录”。
- 星星账单记录收入、支出、动作和时间。
- 奖品兑换申请由家长审批，同意后才扣星。
- 新安装不预置示例奖品；儿童奖励页显示“奖品正在准备中”，验证家长密码后可直达当前小孩的奖励设置。
- 家长新增第一项奖励后自动显示奖品列表；删除最后一项后恢复空状态。

验收标准：

- 主动标记、连续答错和家长指定均能形成正确复习数据。
- 相同任务不会重复加入待复习列表。
- 家长选择的复习内容同步到儿童端。
- 星星收支数量与账单记录一致。
- 奖励只鼓励个人进步，不产生排名和比较。
- 奖励内容按小孩 ID 独立保存，刷新后保持；空状态不影响已有星星余额和账单。

### 二期-5：冒险入口延期占位

状态：开发计划已于 2026-08-12 调整；完整冒险功能延期至第三期。

本期范围：

- 儿童端底部保留“冒险”一级入口，避免后续改变整体信息架构。
- 点击“冒险”后只展示小插图和文案“敬请期待”。
- 不在第二期开放主题岛、关卡、解锁、徽章、闯关星星或重玩功能。
- 已完成的冒险低保真方案和数据结构保留，作为第三期设计与开发参考，不进入第二期验收范围。

验收标准：

- “冒险”入口可正常点击，选中状态正确。
- 页面只显示延期占位内容，不暴露尚未开放的关卡入口。
- 从旧关卡状态刷新或重新进入时，也统一回到“敬请期待”页面。
- 学习、奖品及家长端现有功能和数据逻辑不受影响。

### 二期-6：UI 规范、角色资产与安卓整合

状态：准备启动；先建立正式 UI 规范并确认儿童首页，再扩展全页面和安卓整合。

目标：把已确认的低保真结构转为正式儿童 UI，并整合至安卓 APK。

功能：

- App 名称统一为“Happy 英语”。
- 2D 扁平绘本风，明亮活泼、温柔治愈、简洁高级。
- 主角为黑白奶牛猫，辅助角色为紫色变色龙和鹦鹉。
- 建立颜色、字体、间距、卡片、按钮、图标和插画规范。
- 图片资产通过生图制作并保存本地，再替换低保真占位。
- 将第二期产品逻辑与一期安卓音频能力合并。
- 输出带桌面图标的可安装 APK。

验收标准：

- 学习、奖品、家长端、学习内页及冒险占位页视觉一致。
- 字号偏大、按钮点击区不小于 48dp，主要按钮一行一个。
- 角色造型和配色在不同页面保持一致。
- APK 可安装、启动、显示桌面图标，并通过安卓硬件回归测试。

### 二期-7：教材试用与批量制作

状态：待前三单元正式内容试用通过后启动。

启动条件：

- 学校实际教材已经核对。
- 正式音频与插画版权方案明确。
- 前三单元连续试用 1–2 周。
- 难度、任务量和复习频率通过家长与儿童验证。

后续范围：

- 一年级上册其余单元及 Revision。
- 一年级下册各单元及全册复习。
- 听、说、认读和适量书写内容；主题闯关内容统一在第三期制作。

## 六、第三期：冒险闯关、长期成长与扩展能力

### 三期-1：冒险闯关正式实现

首批单元：

1. `Hello, I'm Andy`：新朋友岛。
2. `I have a new bag`：书包宝藏岛。
3. `Count from one to ten`：数字火车岛。

每座岛包含 6 个连续关卡，覆盖听音选择、认读/计数、词块排序、真实录音、情景对话和综合终章。

统一规则：

- 完成前一座岛后开启下一座岛。
- 每座岛必须按 1–6 关顺序前进。
- 单关通过后不能返回；整岛完成后可从第一关重玩。
- 答错不扣星，可立即重试；连续答错 3 次自动加入复习。
- 前 5 关首次通过各奖励 2 星，终章首次通过奖励 3 星。
- 重玩不重复增加星星。
- 每座岛完成后获得独立主题徽章。

验收标准：

- 三座岛均有 6 个可交互关卡，不使用占位内容。
- 单元解锁、关卡锁定和重玩规则正确。
- 三座岛拥有不同主题、任务内容和反馈文案。
- 录音关支持录制、回放和重新录音，并适配安卓音频硬件。
- 闯关星星与星星账单一致，且按小孩 ID 独立保存。

### 三期-2：个人成长记录

- 学习天数、已完成单元、个人徽章和主题收集。
- 只展示孩子自身成长，不展示排名或其他孩子数据。

### 三期-3：高级家长管理

- 多孩子正式切换。
- 家长修改密码。
- 周报、月报和更详细的薄弱点分析。
- 数据备份、恢复和跨设备迁移。

### 三期-4：可选扩展

- 分级阅读。
- 更多生活场景对话。
- AI 发音建议。
- 云端同步、教师端或家庭共享。

以上能力必须在第二期稳定、教材授权明确且真实使用反馈支持后再决定是否开发。

## 七、全局验收底线

- 不做排名、排行榜、名次和同伴比较。
- 不因答错扣星，不因中断学习清零长期进度。
- 不用考试分数作为儿童端主要反馈。
- 不让孩子每天依赖家长手动生成学习计划。
- 不在未核对教材和版权前批量制作正式内容。
- 不把低保真示例文字、浏览器语音合成或占位插画当作正式教材资产。

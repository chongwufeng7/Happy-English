## 1. 产品概述

### 1.1 产品名称

Happy 英语

### 1.2 产品定位

面向广州小学一年级儿童的轻松英语学习 App。产品以听说启蒙、生活化表达和短时互动为核心，通过每日任务、主题闯关、复习和家庭奖励形成学习闭环，不使用排名、竞赛和同伴比较制造压力。

### 1.3 目标用户

主要用户：

- 2026 年 9 月入读广州小学一年级的儿童。
- 希望陪伴孩子进行每日英语短练的家长。

使用特征：

- 儿童识字量、持续注意力和复杂操作能力有限。
- 家长希望降低每日安排成本，同时保留内容和奖励控制权。
- 主要设备为安卓手机，可能使用扬声器、有线耳机或蓝牙耳机。

### 1.4 核心目标

- 孩子每天可以在较少家长协助下完成约 10–15 分钟学习。
- 系统根据学习进度自动安排新内容和复习内容。
- 通过听、说、认读和适量书写建立一年级英语启蒙基础。
- 让家长看得懂孩子今天学了什么、复习了什么、为什么需要复习。
- 用星星和家庭奖励鼓励个人坚持，不产生比较压力。

### 1.5 当前边界

本 PRD 覆盖第二期产品逻辑及前三单元低保真试点。当前示例文字、浏览器语音合成和占位场景不等于正式教材资产。正式 APK 制作前必须使用学校实际发放的 2026 年教材复核内容，并确认文字、音频和插画授权。

## 2. 产品原则

1. 儿童优先：大字体、大按钮、短句、单页单重点。
2. 轻松学习：答错不扣星，可以重试，不展示失败羞辱文案。
3. 自动续排：家长无需每天手动生成计划。
4. 家长可控：家长可以修改长期计划、指定复习和审批奖励。
5. 结果可解释：复习建议必须展示产生原因。
6. 数据隔离：所有学习数据均关联小孩 ID，为多孩子扩展预留。
7. 内容合规：教材、音频和插画来源必须可核对、可授权。

## 3. 用户角色与权限

### 3.1 儿童端

可以：

- 查看和完成今日任务。
- 查看和完成今日复习。
- 进行听、说、认读、书写和主题闯关。
- 主动标记“还不熟”。
- 获得星星、查看奖励并提交兑换申请。
- 在奖励页查看星星总数并进入星星账单。

不可以：

- 直接批准奖励或扣除星星。
- 修改每日计划和教材内容。
- 不输入密码直接进入家长端。

### 3.2 家长端

可以：

- 查看当天学习和复习情况。
- 设置每日任务数、学习时长和提醒时间。
- 指定复习单元或具体复习内容。
- 从复习建议中同时勾选多条并加入指定复习。
- 修改当前小孩名称和头像。
- 审批或拒绝奖励兑换申请。
- 查看教材内容结构和版本提醒。

### 3.3 角色切换

- 儿童端一级页面右上角显示“切换家长端”。
- 家长端顶部显示“切换儿童端”。
- 双向切换均弹出居中的密码窗口。
- 当前固定密码为 `123456`。
- 密码错误时保留当前角色，不改变页面和学习数据。

## 5. 核心业务流程

### 5.1 每日学习闭环

```text
打开儿童端
→ 系统检查日期并生成/读取今日计划
→ 查看今日任务和今日复习
→ 完成听说读写任务
→ 获得星星
→ 更新今日进度、学习记录和星星账单
```

### 5.2 主动复习闭环

```text
进入任务详情
→ 点击“标记还不熟”
→ 任务进入待复习队列
→ 当日计划重新排程
→ 儿童首页显示复习任务
→ 家长报告显示复习原因
```

### 5.3 自动复习闭环

```text
同一互动练习连续答错
→ 显示 1/3、2/3
→ 第 3 次答错自动加入复习
→ 错误连续计数归零
→ 家长报告显示“同一练习连续答错3次”
```

答对后，当前练习的连续错误计数立即归零。

### 5.4 家长指定复习

```text
进入家长端报告
→ 查看复习建议及原因
→ 勾选一条或多条建议
→ 添加至指定复习内容
→ 同步当前孩子的复习队列
→ 儿童端按每日计划规则安排复习
```

### 5.5 奖励兑换

```text
孩子选择奖品
→ 提交兑换申请
→ 家长在概览中审批
→ 同意：扣除星星并写入账单
→ 拒绝：不扣星星
```

## 6. 每日学习计划规则

### 6.1 数据维度

每日计划按以下组合独立生成：

```text
childId + localDate
```

### 6.2 默认生成规则

- 家长从未设置时，默认每天 3 项、约 12 分钟。
- 没有待复习内容时：安排 3 项当前单元尚未完成的新内容。
- 有待复习内容时：优先安排 1 项复习＋2 项当前单元新内容。
- 当家长将每日任务数修改为 1–4 项时，系统按设置数量生成；有复习时仍优先安排 1 项复习，其余为新内容。

### 6.3 复习优先级

1. 家长指定的具体复习内容。
2. 连续答错 3 次的内容。
3. 孩子主动标记“还不熟”的内容。
4. 家长指定复习单元中的内容。

相同任务只进入一次待复习列表。

### 6.4 当天固定规则

- 当天首次生成后，普通刷新、退出和重新进入不会改变计划。
- 家长主动修改计划、家长新增指定复习、孩子主动标记或连续答错 3 次时允许重新排程。
- 已完成任务不会因重新排程丢失完成记录或重复扣除长期进度。

### 6.5 日期切换规则

进入新的一天时：

- 清零今日完成、今日星星和今日记录。
- 生成新的当日计划。
- 保留总星星、历史星星账单、单元进度、闯关进度、复习历史和孩子资料。

## 7. 儿童端详细需求

### 7.1 首页

必须包含：

- 左上角页面名称“Happy 英语”。
- 右上角“切换家长端”。
- 角色欢迎区和当前孩子名称。
- “开始学习”主按钮。
- 今日进度数字和进度条。
- 今日星星数量。
- 今日任务列表。
- 今日复习列表。
- 底部导航：首页、闯关、奖励。

交互规则：

- “开始学习”优先打开今日未完成的复习或新任务。
- 点击任务状态进入任务详情。
- 今日进度按今日计划中的全部复习和新任务计算。

### 7.2 任务详情

页面包含：

- 任务类型、标题、单元和任务说明。
- 学习操作区。
- 体验/播放/录音等操作。
- “完成任务＋3星”。
- 独立醒目的“这项还不熟？”区域。
- “标记还不熟”按钮；加入后变为“已加入今日复习”并禁用重复操作。

### 7.3 听、说、认读和书写

- 听：播放示范音频，可重复播放。
- 说：申请麦克风权限，录音、停止、回放、重新录音、确认。
- 认读：图片或文字选择，点击区域足够大。
- 书写：描写/书写区域，提供清除和重新写。

正式安卓版本必须兼容手机扬声器、有线耳机和蓝牙耳机，并处理权限拒绝、设备切换、播放失败和录音失败。

### 7.4 星星展示

- 首页和闯关一级页不显示总星星。
- 奖励页标题左侧区域显示总星星。
- 点击总星星进入星星账单。
- 星星账单显示收入、支出、对应动作和发生时间，并返回进入前页面。

## 8. 三单元主题闯关

### 8.1 统一闯关规则

- 三座岛按照 Unit 1 → Unit 2 → Unit 3 的顺序解锁。
- 每座岛 6 关，必须顺序完成。
- 已通过单关不能返回，只能继续下一关。
- 答错不扣星，可以立即重试。
- 连续答错 3 次，自动加入该关关联的复习任务。
- 前 5 关首次通过各奖励 2 星。
- 第 6 关首次通过奖励 3 星并获得主题徽章。
- 整岛完成后可以从第 1 关重新玩。
- 重玩必须顺序前进，不重复增加星星。

## 9. 奖励与星星规则

### 9.1 星星收入

- 完成每日任务：首次完成当天任务获得 3 星。
- 闯关第 1–5 关：首次通过每关获得 2 星。
- 闯关终章：首次通过获得 3 星。
- 重复点击完成、返回重进或整岛重玩不得重复增加星星。

### 9.2 星星支出

- 孩子提交兑换申请时不立即扣星。
- 家长同意后扣除对应星星。
- 家长拒绝或余额不足时不扣星。

### 9.3 星星账单

每条记录包含：

- 记录 ID。
- 收入或支出数量。
- 产生动作。
- 发生时间。
- 当前孩子 ID。

## 10. 家长端详细需求

### 10.1 概览

- 顶部显示“概览”和“切换儿童端”。
- 今日完成任务数。
- 今日学习时长（低保真阶段允许模拟）。
- 当前每日计划摘要。
- 奖励兑换待审批列表。

### 10.2 任务

- 每日任务数量：1–4 项。
- 每日学习时长：5、10、12、15 分钟。
- 学习提醒时间。
- 指定复习单元。
- 已指定具体复习内容。
- 提示“计划持续生效，无需每天重复设置”。

保存后同步到当前孩子；修改当天计划时允许重新排程。

### 10.3 报告

标题格式：`{小孩名称}学习报告`。

必须包含：

- 今日学习记录。
- 今日复习记录。
- 听、说、读、写数量概况。
- 复习建议。
- 复习建议产生原因。
- 多选建议和“添加至指定复习内容”按钮。
- 已指定内容显示“已指定”并禁止重复添加。

复习建议来源：

- 孩子主动标记为还不熟。
- 同一练习连续答错 3 次。
- 当前主题尚未完成。
- 家长已经指定复习。

### 10.4 设置

标签页一：我的小孩。

- 点击头像打开本机相册。
- 支持 PNG、JPEG、WebP。
- 原图最大 12MB。
- 保存前自动压缩至最大边 512px，并使用适当质量的 WebP。
- 编辑小孩名称并同步到儿童欢迎语、闯关对话和报告标题。

标签页二：教材内容。

- 展示册、单元、学习目标、词汇、表达、技能、任务和复习关系。
- 展示教材内容待核对状态。
- 不在页面展示内部研发说明。

设置页底部显示版本号 `V1.0` 和教材授权提醒。

## 12. 状态与异常处理

### 12.1 空状态

- 今日无复习：显示“今天暂时没有复习内容”。
- 今日无完成：显示“今天还没有完成记录”。
- 今日无复习记录：显示“今天还没有复习记录”。
- 无兑换申请：显示“暂无兑换申请”。
- 无星星记录：显示“暂时没有星星记录”。

### 12.2 权限和硬件异常

- 麦克风权限未授权：解释用途并允许重新申请。
- 权限永久拒绝：引导家长前往系统设置。
- 录音设备占用：提示关闭其他录音应用后重试。
- 播放无声：检查媒体音量、静音和当前输出设备。
- 耳机切换：保持当前页面和录音状态，必要时提示重新录制。

### 12.3 数据异常

- 本地数据读取失败时回退到默认结构，不导致白屏。
- 版本升级执行数据迁移，不清空长期学习数据。
- 旧版星星账单缺少 `childId` 时自动迁移，不影响余额和历史收支。
- 重复提交、重复点击和页面刷新不得重复加星或重复扣星。

## 13. UI 与可用性要求

- 正式视觉：2D 扁平插画、绘本风、明亮活泼、温柔治愈、简洁高级。
- 主角：黑白奶牛猫。
- 辅助角色：紫色变色龙、鹦鹉。
- 儿童端字号偏大，重要数据简单且醒目。
- 主要点击区域不小于 48dp，主操作按钮建议高度不小于 56dp。
- 一个主要按钮占一行，按钮间距不少于 12dp。
- 页面内容保持适当留白，避免复杂信息和密集文字。
- 状态不能只依赖颜色，需同时使用文字或图标。
- 不使用排名、奖杯榜、同伴头像列表等竞争性表达。

## 14. 非功能需求

### 14.1 性能

- 首页冷启动后尽快显示本地计划，不等待网络。
- 头像压缩和本地数据保存不能明显阻塞操作。
- 插画资源应按安卓屏幕密度和包体目标压缩。

### 14.2 离线与存储

- 核心每日学习、闯关和星星功能应支持离线。
- 当前低保真使用浏览器 localStorage；正式安卓版本需迁移到可靠本地存储。
- 云端同步不属于第二期必做范围。

### 14.3 隐私

- 默认不采集不必要的儿童个人信息。
- 头像、录音和学习数据优先保存在本机。
- 若未来启用云端，必须增加家长同意、隐私说明和儿童数据保护方案。

### 14.4 兼容性

- 安卓手机竖屏为主。
- 适配常见屏幕宽度、系统字体缩放和安全区域。
- 覆盖扬声器、有线耳机、主流蓝牙耳机和常见安卓权限流程。

## 15. 第二期验收标准

### 15.1 儿童端

- 一级导航只有首页、闯关、奖励。
- 首页和闯关不显示总星星；奖励页显示并可进入账单。
- 今日计划能按日期自动生成并在次日正确刷新。
- 孩子能完成任务、主动标记复习并获得星星。
- 三座主题岛均包含 6 个可交互关卡。
- 单元解锁、关卡顺序、首次奖励和重玩规则正确。
- 连续答错 3 次能加入对应单元的复习任务。

### 15.2 家长端

- 使用 `123456` 成功切换，错误密码不能进入。
- 家长设置可以同步当前孩子。
- 报告标题带入孩子名称。
- 今日学习记录和今日复习记录分别展示。
- 复习建议可多选并添加到指定复习内容。
- 奖励同意后才扣星，拒绝不扣星。
- 头像可以选择、压缩、保存并重新显示。

### 15.3 数据

- 刷新和重新打开后数据不丢失。
- 次日今日数据清零，长期数据保留。
- 星星余额等于账单收入减支出后的结果。
- 每个孩子的数据通过 childId 独立关联。
- 重复操作不会重复加星或扣星。

### 15.4 安卓硬件

- 示范音频可从扬声器、有线耳机和蓝牙耳机播放。
- 麦克风权限申请、录音、停止、回放和重新录音正常。
- 权限拒绝、无声和设备切换有明确提示。
- APK 可安装、启动，并显示正确名称和桌面图标。

## 17. 风险与待确认事项

- 2026 年学校实际发放教材的版本、版次和内容仍需实物核对。
- 教材音频、课文和插画的使用权需要明确。
- 当前三座岛内容用于验证玩法，正式文字和语音必须按教材复核。
- 安卓不同品牌对蓝牙录音、音频路由和后台权限的实现存在差异，需要真机测试。
- 固定密码 `123456` 适合当前家庭原型，正式长期使用版本应支持家长修改密码。
- 多孩子数据结构已经预留，但正式多孩子切换界面属于第三期。
- AI 发音评分、云端同步、教师端和排名均不属于当前版本范围。

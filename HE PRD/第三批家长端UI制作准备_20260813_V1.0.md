## 1. 本批范围

第三批只制作家长端核心闭环，不扩大到儿童冒险、APK 和动效：

1. 家长概览。
2. 学习报告。
3. 家长设置框架。
4. 我的小孩及任务设置。
5. 奖励设置。
6. 教材内容。
7. 奖励审批与必要确认弹窗。

多小孩能力只保留底层数据对应关系，本批界面不提供新增、删除或切换多个小孩的操作。

## 2. 公共框架规则

1. 所有一级页面统一使用 390 × 844 画板。
2. 保留 Android 状态栏、顶部安全区和底部安全区。
3. 底部导航贴住画板底部，不跟随滚动内容移动。
4. 页面内容区可纵向滚动，并预留底部导航高度，禁止被导航遮挡。
5. 顶部栏、底部导航、按钮、卡片、标签页、输入框和弹窗优先使用 Figma 组件实例。
6. 所有按钮文字水平、垂直居中；最低可点击高度 48px。
7. 卡片不得依赖固定高度容纳可变文案；状态说明、价格和操作使用 Auto Layout 自动撑高。

## 4. 页面与状态清单

### 4.1 家长概览

- 今日学习进度、今日学习时长、今日星星。
- 当前学习计划摘要。
- 待审批奖励列表。
- 最近处理记录。
- 空状态：无学习记录、无待审批申请、无最近处理记录。
- 数据状态：部分完成、全部完成、审批失败。

### 4.2 学习报告

- 标题使用当前小孩名称，例如“Happy学习报告”。
- 今日学习记录。
- 今日复习记录。
- 听、说、读、写概况。
- 复习建议多选。
- 将勾选建议添加至指定复习内容。
- 空状态：无学习记录、无复习记录、无复习建议。
- 完成状态：部分建议已指定、全部已指定、添加成功。

### 4.3 家长设置

三个标签页：

1. 我的小孩：头像、名称、任务设置。
2. 奖励设置：奖励增删改、图片、标题、星星价格和备注。
3. 教材内容：册—单元—目标—词汇—表达—技能—任务—复习关系。

设置只作用于当前小孩，学习进度、星星、复习、奖励和任务计划均按小孩 ID 独立保存。

### 4.4 奖励审批弹窗

- 同意：提示扣除星星并二次确认。
- 拒绝：不扣星星并二次确认。
- 星星不足。
- 奖品已删除。
- 申请已处理，禁止重复审批。
- 审批异常，保留失败原因。

## 5. 需要复用的组件

- Parent Shell：顶部栏、底部导航。
- Button：Primary、Secondary、Text、Disabled、Loading。
- Metric Card：普通数据、零数据、完成数据。
- Status Badge：待审批、已同意、已拒绝、审批失败。
- Tabs：默认、选中、按下。
- Form Field：默认、聚焦、已填写、错误、禁用。
- Dialog：确认、输入错误、操作结果。
- Empty State：记录、建议、奖励设置空状态。
- Notice：成功、警告、错误。

## 6. 绘制顺序

1. 核对家长概览、报告、设置低保真内容和状态。
2. 补齐家长端信息卡、标签页、审批卡、表单和弹窗组件。
3. 绘制家长概览默认与空状态。
4. 绘制学习报告默认与空状态。
5. 绘制设置三个标签页及关键校验状态。
6. 绘制审批确认、审批失败和重复处理状态。
7. 逐页简单验证后更新 HTML；不改业务逻辑和数据结构。
8. 用户确认第三批后保存 Git 版本，再进入公共状态补齐。

## 7. 验收标准

- 所有画板均为 390 × 844。
- 状态栏、安全区、顶部栏和底部导航位置一致。
- 底部导航真正贴底，长内容可滚动且不被遮挡。
- 按钮文字居中，点击区域不小于 48px。
- 长标题、长备注、错误信息和审批说明不重叠、不溢出。
- 页面风格与儿童端保持同一套颜色、字体、圆角、阴影和交互反馈。
- HTML 只更新视觉层，保留现有数据、路由和事件。
- 本批只做简单功能验证，详细 UI 走查等待用户指令。

## 8. 明确不做

- 儿童冒险及岛屿关卡。
- 多小孩管理界面。
- 动效规范和正式动效。
- Compose 工程迁移。
- APK 构建。

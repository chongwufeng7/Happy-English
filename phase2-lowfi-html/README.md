# Happy 英语｜第二期 HTML 低保真

## 用途

此原型用于确认第二期的信息架构、页面流程、数据联动与闯关逻辑，不代表最终 UI，也不包含正式教材音频、插图或完整课文。

## 当前范围

- 儿童端底部只保留：首页、闯关、奖励；
- 儿童端一级页面名称统一显示在顶部左侧，右侧通过“切换家长端”进入家长端；星星总数仅在“奖励”页面展示并可进入星星账单；
- 二级页面顶部改为左侧返回、中间页面名称、右侧留空；
- 任务详情、冒险岛、具体关卡和星星账单采用统一内页留白；操作按钮纵向排列，一行一个；
- 内页隐藏底部主导航，完成或返回后再回到一级页面；
- 点击顶部星星可进入“星星账单”，查看收入、支出、对应动作和发生时间；
- 星星账单会记住进入来源，点击返回可回到原一级页面；
- 今日任务负责每天短练，复习内容直接出现在首页；
- 闯关负责综合运用教材主题，不重复展示首页任务；
- 家长端包含概览、学习报告、当前小孩的任务设置、奖励维护与审批；
- 家长端底部包含“概览、报告、设置”；设置内含“我的小孩、奖励设置、教材内容”三个标签页；
- “我的小孩”下方展示该小孩的任务设置，任务计划、提醒、复习内容均跟随当前小孩独立保存；
- “奖励设置”支持新增、编辑和删除奖励，可上传并自动压缩奖励图片，设置标题、星星价格和备注说明；奖励内容跟随当前小孩保存；
- 点击孩子头像即可从本机相册选择图片，图片在保存前自动压缩至最大边 512px；
- 设置页底部显示版本号 `V1.5`，并保留教材复核与授权提醒；
- 儿童端“冒险”入口暂时显示“小插图＋敬请期待”，完整冒险关卡延期至第三期；
- 首次安装不再预置小孩、星星和奖励：先进入初始化建档页，建立首个小孩后以 `0` 颗星星开始并自动生成第一天计划；
- 首页补齐“今日全部完成”“暂无可安排任务”和“整册内容完成”状态，最后一项任务完成时展示结算弹窗；
- 奖励兑换增加二次确认，家长审批增加确认弹窗；儿童端可识别待确认、已兑换、家长暂未同意、审批未完成和星星不足；
- 家长概览新增最近处理记录，保留同意、拒绝和审批失败原因；
- 三座主题岛全部完成后显示总完成状态与庆祝弹窗；
- 新安装时奖励页显示空状态；家长验证密码后可直接进入当前小孩的奖励设置，新增第一项奖励后自动显示奖品列表；
- 小孩资料支持修改名称和上传头像，并使用 `childId → learningByChildId` 保存各自的学习进度、星星、复习与闯关数据，为后续多小孩扩展预留结构；
- 学习报告标题自动带入当前小孩名称，并分别展示“今日学习记录”和“今日复习记录”；
- “复习建议”支持同时勾选多条内容，添加为当前孩子的指定复习任务，并同步到儿童端“今日复习”；
- 儿童任务页提供醒目的“标记还不熟”入口；同一互动练习连续答错 3 次时自动加入复习，答对后连续错误计数清零；
- 每日计划按“小孩 ID + 日期”自动生成：默认优先 1 项复习和 2 项当前单元新内容；未设置新计划时沿用最近设置，新的一天只重置今日数据，不清除总星星和长期进度；
- 家长端与儿童端双向切换密码：`123456`；
- 不包含排名、同伴比较和竞赛。

## 教材主题闯关

前三个单元均已制作成六关连续主题岛：

1. 清晨码头：听音找到说 `Good morning!` 的鹦鹉；
2. 名字森林：听介绍，把姓名牌交给正确角色；
3. 句子石桥：按顺序拼出 `Hello, I'm HAPPY.`；
4. 回声山谷：真实录音、回放并支持重新录制 `My name is HAPPY.`；
5. 朋友小屋：完成三轮连续见面对话；
6. 友谊派对：完成三项综合任务，点亮整座岛。

主题 2“书包宝藏岛”包含听辨学习用品、听句选物、句子排序、书包表达录音、学习用品对话和综合收纳终章。

主题 3“数字火车岛”包含听数字选车厢、数星星、数字排序、1–10 报数录音、缺失数字挑战和综合终点庆典。

三座岛按单元顺序解锁，每岛关卡按顺序前进；答错不扣星并可立即重试，连续答错 3 次自动加入复习。关卡一旦通过便不能返回。前五关首次通过各奖励 2 颗星，终章首次通过奖励 3 颗星；整岛完成后开放从头重玩，重玩不再增加星星。

## 本地打开

直接双击 `index.html` 即可运行，也可以在本目录启动静态文件服务器后通过手机浏览器访问。原型数据保存在浏览器 `localStorage` 中。

## 建议验收流程

1. 确认儿童端一级导航只有首页、闯关和奖励；首页、闯关不显示总星星，奖励页显示总星星且点击后进入星星账单；
2. 进入“闯关”，确认新朋友岛、书包宝藏岛和数字火车岛均展示 0/6，后续岛屿按单元顺序锁定；
3. 进入新朋友岛，确认只有第一关可进入，其余关卡锁定；
4. 第一关故意答错，确认不扣星、可继续选择；
5. 答对并通过，确认进度变为 1/6、总星星首次增加 2，第二关解锁；
6. 依次体验听音、找角色、拼句、录音与重录、情景对话和终章；
7. 完成第六关，确认出现“新朋友”徽章并解锁书包宝藏岛；
8. 确认已经通过的单关无法返回进入；
9. 依次完成书包宝藏岛和数字火车岛，确认每座岛都有 6 个可交互关卡和独立徽章；
10. 完成整座岛后点击“重新玩”，确认从第一关重新开始，再次通过不重复增加星星；
11. 清除本站数据后重新打开，确认先进入首次建档页，创建小孩后星星为 0、奖励为空，并自动生成第一天计划；
12. 完成当天最后一项任务，确认出现今日完成结算弹窗；完成全部学习内容后确认首页显示整册完成状态；
13. 申请兑换奖品，确认先出现二次确认；分别验证家长同意、拒绝和审批时余额不足三种结果；
14. 家长批准后确认星星账单新增对应支出、时间和当前小孩 ID；
15. 完成三座主题岛，确认出现全部冒险岛完成状态。

## 当前限制

- 浏览器语音合成仅用于验证播放流程，不是正式教材录音；
- 回声山谷使用浏览器麦克风，需要用户授权；正式安卓版本还需继续验证扬声器、有线耳机和蓝牙耳机；
- 角色与场景仍为低保真占位，UI 确认后再生成插画并替换；
- 正式制作前仍需用学校实际发放的 2026 年教材复核文字、顺序、音频和版权信息；
- 三座主题岛当前用于验证结构、互动和规则，正式教材文字与音频仍需根据学校实际教材复核。
